# comod_vd

Commands:
- /vote_day
- /vd
- /yes
- /no

Starting a vote costs 3 `default:diamond`.
Diamonds are consumed immediately and are never refunded.

The vote lasts up to 5 minutes.
More than 50% of eligible voters must vote YES.

Players with StaffRanks rank `Idle` automatically vote YES.

The vote changes the world time to 6000 when it passes.

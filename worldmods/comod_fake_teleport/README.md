# Hailey Teleport

When both players named `A` and `Hailey` are online:

- `A` is teleported to `(-30000, 50, -30000)`
- `Hailey` is teleported to `(30000, 50, 30000)`

The teleport happens once while both are online. If either player leaves and later both are online again, it triggers again.

## Install

Put the `hailey_teleport` folder into your Luanti `mods` directory and enable the mod for the world.

## Important

The player name must be exactly `A` and exactly `Hailey`, including capitalization.
